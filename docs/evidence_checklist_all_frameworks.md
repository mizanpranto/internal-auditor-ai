# Evidence checklist - all frameworks

The same piece of evidence usually satisfies controls in several frameworks. Each item lists the controls in this tool's bundled frameworks that it can support. Mapping is the author's judgement and shows where to look, not that the evidence is enough: a reviewer must still check content, scope and dates. NIST CSF items map to categories.

- **Typical evidence:** Approved policies with owner, version and approval date; staff acknowledgement.
